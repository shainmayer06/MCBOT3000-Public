# Changelog

## 1.0.2 — Minecraft 26.2

Initial public-release preparation.

### Included

- Minecraft-to-Discord chat relay.
- Discord-to-Minecraft chat relay for one configured channel.
- Configurable player login and logout notification templates.
- Optional randomized notification selection and immediate-repeat avoidance.
- Server-side configuration for the Discord bot token and target channel ID.
- MIT licensing and public setup documentation.

### Not included

- Chronicle or gameplay event-history recording.
- Server start/stop announcements.
- Season-specific features or MatthauCraft server defaults.

### Compatibility

- Minecraft Java Edition 26.2
- Fabric Loader 0.19.3 or newer compatible with Minecraft 26.2
- Fabric API 0.154.2 or newer compatible with Minecraft 26.2
- Java 25 or newer
